# E-Commerce Sales Analysis using Pandas
A simple but effective data analysis project using **Python and Pandas** to perform analysis on the e-commerce sales data and derive valuable business insights.

## Project Overview
This is a project where we focus on data cleaning, analysis and summary of e-commerce sales data.

Some of the analyses performed include product performance, category wise sales, customers expenditure, city wise revenue, monthly sales trends and payment methods.

## Technologies Used
* Python
* Pandas
* CSV

## 📊 Analysis Performed

* Inspecting the data
* Checking missing values
* Detecting and removing duplicate rows
* Cleaning the data
* Converting date
* Removing invalid values
* Calculating revenue
* Top 10 products based on quantity
* Top 10 products based on revenue
* Category wise revenue
* Category wise quantity
* City wise revenue
* Customer expenditure analysis
* Monthly revenue analysis
* Payment method analysis
* Average order value
* Customers making more than 5 orders
* Products having above average revenue

## How to Run
1. Clone this repo.
2. Ensure Python and Pandas are installed.
3. Save `Project.py` and `ecommerce_sales.csv` in the same directory.
4. Run:Project.py
